# Assessment Pack Structure

```text
README.md                 Assessment basis, overall score, common actions
01_robot_pkg.md           Broad robot-learning/navigation package
02_balancing_robot.md     Two-wheel description/simulation package
03_cad_description.md     Mobile-manipulator description package
04_drone_pkg.md           Kinematic drone-control package
05_spider_pkg.md          Eight-legged gait/mapping package
```

Each report follows the same rubric: current implementation, strengths, verified issues with impact and corrective action, PG-level improvement path, and conclusion. Findings labelled “verified” come from the supplied source; runtime behaviour still requires ROS 2/Gazebo execution.
