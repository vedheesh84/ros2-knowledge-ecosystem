## 1. Mathematical Formulation of Multi-Robot Map Merging

Let $m_1(x, y)$ and $m_2(x, y)$ be the 2D local occupancy grid probabilities generated by Robot 1 and Robot 2 respectively.
The log-odds representation of occupancy is defined as:
$$L(m(x, y)) = \ln \left( \frac{P(m(x, y) = 1)}{1 - P(m(x, y) = 1)} \right)$$

When combining independent spatial observations from two robots:
$$L(m_{\text{fused}}(x, y)) = L(m_1(x, y)) + L(m_2(x, y)) - L_0$$
where $L_0$ is the prior log-odds of occupancy (typically 0 for unknown cells).

## 2. Occupancy Grid Data Layout & Alignment

ROS 2 `nav_msgs/msg/OccupancyGrid` stores cell probabilities as an array of signed 8-bit integers (`int8`):
- `-1`: Unknown space
- `0`: Free space ($P(\text{occ}) = 0$)
- `100`: Obstacle ($P(\text{occ}) = 1$)

```text
Robot 1 Local Grid (/robot1/map)       Robot 2 Local Grid (/robot2/map)
┌───┬───┬───┐                          ┌───┬───┬───┐
│ 0 │ 0 │100│                          │-1 │ 0 │ 0 │
├───┼───┼───┤            +             ├───┼───┼───┤
│ 0 │100│-1 │                          │ 0 │100│100│
└───┴───┴───┘                          └───┴───┴───┘
                  ▼
         Merged Global Grid (/map)
         ┌───┬───┬───┐
         │ 0 │ 0 │100│
         ├───┼───┼───┤
         │ 0 │100│100│
         └───┴───┴───┘
```

## 3. High-Performance NumPy Map Merger Implementation

```python
import numpy as np

def merge_occupancy_grids(grid1_data, grid2_data):
    """
    Merges two occupancy grids using max-certainty Bayesian rule.
    """
    g1 = np.array(grid1_data, dtype=np.int8)
    g2 = np.array(grid2_data, dtype=np.int8)
    
    # Handle free space vs unknown space
    fused = np.maximum(g1, g2)
    return fused.tolist()
```
